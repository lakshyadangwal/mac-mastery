# 07 — Hidden Features

Your Mac is misbehaving, or you just want to see what's under the hood. These are the secret controls most people never find.

## Shortcuts

| Keys | What it does | Level | Memory hook |
|------|--------------|-------|-------------|
| ⌥ + click menu bar icon | Reveal hidden menu options | Power User | Option-click shows the secret second menu |
| ⌥ ⌘ Esc | Force Quit apps | Beginner | The three-finger salute when an app stops breathing |
| ⌘ R at startup | Boot into Recovery Mode | Wizard | Hold Command + R before the logo appears |
| ⌥ at startup | Startup Manager — choose boot disk | Wizard | Option at startup picks which disk to boot |
| ⌘ ⌥ P R at startup | Reset NVRAM | Wizard | Hold these four keys before startup (Intel Macs) |
| ⌃ ⌘ Q | Lock your screen | Beginner | Lock your Mac fast — walk away safely |
| ⌥ ⌘ 8 | Toggle Accessibility zoom | Power User | Zoom in on anything, anywhere on screen |
| ⌥ ⌘ = | Zoom in | Power User | Equals makes everything bigger |
| ⌥ ⌘ - | Zoom out | Power User | Minus shrinks it back |
| ⌘ , | Open app preferences | Beginner | Comma opens settings in almost every app |
| ⌘ Space → "Text Replacements" | Auto-expand short phrases | Beginner | Type "omw" and it becomes "On my way!" |
| ⌘ ⇧ Q | Log out of your Mac | Beginner | Log out quickly when you're done |
| ⌥ ⌘ D | Hide or show the Dock | Power User | Option + Command D — the Dock disappears |
| ⌃ ⌘ ⎋ | Force Quit (same as ⌥ ⌘ Esc) | Beginner | Another way to say "this app is done" |

> Some startup shortcuts (⌘ R, ⌥, ⌘ ⌥ P R) must be held *before* the Apple logo appears on Intel Macs. On Apple Silicon Macs, press and hold the power button at startup to see startup options.

## Try it now

1. Press **⌃ ⌘ Q** to lock your Mac instantly
2. Hold **⌥** and click the Wi-Fi icon in the menu bar
3. Press **⌥ ⌘ 8** to toggle screen zoom, then **⌥ ⌘ =** to zoom in
