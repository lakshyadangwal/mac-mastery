# 02 — Window Management

Twenty windows. Three desktops. You can't find the Slack window you need. Welcome to window management — where you stop hunting and start commanding.

> **Split View:** macOS doesn't have a single keyboard shortcut for Split View. Hold **⌥** and click the green button in any window's top-left corner, then pick "Tile Window to Left of Screen" or "Tile Window to Right of Screen."

## Shortcuts

| Keys | What it does | Level | Memory hook |
|------|--------------|-------|-------------|
| ⌃ ⬆ | Open Mission Control | Beginner | Up to see everything — like a drone over your desk |
| ⌃ ⬇ | Show every window of one app | Power User | Down pours out every window of the front app |
| ⌃ ⬅ / ➡ | Move between Spaces/desktops | Beginner | Left and right hop between desktops like stepping stones |
| ⌃ ⌘ F | Toggle full screen | Beginner | F for Full — the app takes over the whole stage |
| ⌘ ` | Cycle windows of the same app | Beginner | ` wiggles between windows like a little snake |
| ⌥ ⌘ H | Hide every other app | Power User | Hide others — solo mode for the front app |
| ⌥ ⌘ M | Minimize all windows of the app | Power User | Minimize the whole app — desk cleared in one tap |
| ⌘ W | Close the current window | Beginner | W for Window — closes just this pane |
| ⌘ H | Hide the current app | Power User | H for Hide — the app vanishes like a ninja |
| ⌘ M | Minimize the window | Beginner | M for Minimize — shrinks into the dock like a turtle |
| F11 / fn ⬆ / ⌘ F3 | Show Desktop | Beginner | F11 throws every window aside so you can see the desk |
| ⌘ Tab | Switch between apps | Beginner | Tab cycles apps like changing TV channels |
| ⌥ + click green button | Tile window left/right (Split View) | Power User | Option-click the green button to pick left or right tile |
| ⌃ ⌘ F (again) | Exit full screen | Beginner | Press it again — the stage shrinks back |

## Try it now

1. Press **⌃ ⬆** to open Mission Control
2. Press **⌃ ⬅** or **⌃ ➡** to hop to another Space
3. Press **⌥ ⌘ H** to hide everything except your current app
