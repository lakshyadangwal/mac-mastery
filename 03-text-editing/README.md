# 03 — Text Editing

You're mid-email and the cursor is in the wrong place. You need to jump, select, delete a whole word, or drop an emoji — without touching the mouse.

## Shortcuts

| Keys | What it does | Level | Memory hook |
|------|--------------|-------|-------------|
| ⌘ ← | Jump to the start of the line | Beginner | Command + left teleports you to the beginning of the line |
| ⌘ → | Jump to the end of the line | Beginner | Command + right shoots you to the end |
| ⌥ ← | Jump one word left | Power User | Option hops over whole words like a bunny |
| ⌥ → | Jump one word right | Power User | Same bunny, going the other way |
| ⌘ ↑ | Jump to the top of the document | Beginner | Up goes up — straight to the top |
| ⌘ ↓ | Jump to the bottom of the document | Beginner | Down dives to the bottom |
| ⇧ ⌘ ↑ | Select everything to the top | Power User | Select all the way up to the ceiling |
| ⇧ ⌘ ↓ | Select everything to the bottom | Power User | Select all the way down to the floor |
| ⌥ ⌫ | Delete the word to the left | Power User | Option + delete eats a whole word in one bite |
| ⌃ K | Delete to the end of the line | Power User | Control + K kills the rest of the line (emacs style) |
| ⇧ ⌥ ← | Select the word to the left | Power User | Grab the word on the left, one hop |
| ⇧ ⌥ → | Select the word to the right | Power User | Grab the word on the right, one hop |
| ⌃ ⌘ Space | Open the emoji picker | Beginner | Control + Command + Space opens the emoji universe |
| ⌥ e, then a | Type á (accents) | Power User | Option + letter primes the accent pump, then type the letter |
| ⌥ n, then n | Type ñ | Power User | Option + n then n gives you ñ — like a little hill |
| ⌥ u, then u | Type ü | Power User | Option + u puts umbrellas (dots) over the next vowel |
| ⌃ A | Jump to the start of the line | Power User | Control + A goes to the start (emacs style) |
| ⌃ E | Jump to the end of the line | Power User | Control + E goes to the end (emacs style) |

## Try it now

1. Type a sentence, then press **⌥ ←** to jump back one word
2. Press **⌥ ⌫** to delete that word
3. Press **⌃ ⌘ Space** and insert an emoji
