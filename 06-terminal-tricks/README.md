# 06 — Terminal Tricks

You opened Terminal and it stares back at you, blank and judgmental. These commands make it useful — and a little fun.

## Shortcuts and commands

| Keys / Command | What it does | Level | Memory hook |
|----------------|--------------|-------|-------------|
| open . | Open the current folder in Finder | Beginner | Dot means "here" — opens this folder in Finder |
| pbcopy | Copy command output to the clipboard | Power User | Pipe anything into pbcopy to snag it |
| pbpaste | Paste the clipboard into Terminal | Power User | pbpaste spits the clipboard back out |
| caffeinate -i | Keep your Mac awake | Power User | caffeinate keeps your Mac from dozing off |
| defaults write | Tweak hidden macOS settings | Wizard | defaults write changes settings Apple hides |
| say | Make your Mac speak | Beginner | say makes your Mac talk back to you |
| !! | Repeat the last command | Power User | !! runs the last thing again — like a parrot |
| sudo !! | Repeat the last command as admin | Wizard | sudo !! says "do it again with authority" |
| ⌃ C | Cancel the running command | Beginner | Control + C kills the command in its tracks |
| ⌃ L | Clear the screen | Beginner | Control + L wipes the screen clean |
| ⌥ ⌘ C | Copy text in Terminal | Beginner | Copy without touching the mouse |
| ⌥ ⌘ V | Paste text in Terminal | Beginner | Paste without right-clicking |
| open -a "App Name" file | Open a file in a specific app | Power User | Tell macOS exactly which app to use |
| pbcopy < file.txt | Copy a file's contents to clipboard | Power User | Send a whole file straight to the clipboard |
| history | Show past commands | Beginner | history remembers what you typed |
| ⌥ ← / → | Jump word-by-word in Terminal | Power User | Option + arrows hop through the command line |

## Try it now

1. Type `open .` and press ⏎ to open this folder in Finder
2. Type `say "Hello, Mac"` and press ⏎ to hear your Mac speak
3. Type `!!` to repeat the last command
