# 04 — Finder and Files

You're staring at Finder like it's a maze. You need to rename ten files, peek inside one, or jump to a buried folder — fast.

## Shortcuts

| Keys | What it does | Level | Memory hook |
|------|--------------|-------|-------------|
| ⌘ N | New Finder window | Beginner | N for New — a fresh window appears |
| ⌘ ⇧ N | New folder | Beginner | N for New folder — make a home for your files |
| ⌘ ⌫ | Move selected file to the Trash | Beginner | Command + delete sends it to the bin |
| ⇧ ⌘ ⌫ | Empty the Trash | Power User | Shift confirms — you really mean to say goodbye |
| Space | Quick Look preview | Beginner | Space peeks inside files like looking through a keyhole |
| ⌘ I | Get Info | Beginner | I for Information — the file's ID card |
| ⌘ ⇧ G | Go to Folder | Power User | G for Go — type any path and teleport there |
| ⌘ ⇧ . | Show hidden files | Power User | Dot reveals dotfiles like magic glasses |
| ⌘ D | Duplicate the file | Beginner | D for Double — makes an instant twin |
| ⌘ ⌥ P | Show the Path Bar | Power User | P for Path — shows exactly where you are |
| ⌘ ⌥ S | Show the Sidebar | Power User | S for Sidebar — brings the sidebar back |
| ⌘ ↑ | Open the enclosing folder | Beginner | Up goes to the parent folder |
| ⌘ ↓ | Open the selected file or folder | Beginner | Down dives into what you selected |
| ⌘ F | Find files with Spotlight | Beginner | F for Find — hunt down any file |
| ⌥ ⌘ V | Move the file (paste as move) | Power User | Option + V moves instead of copies — cut and paste for files |
| ⌘ ⇧ H | Go to your Home folder | Beginner | H for Home — teleports you home |
| ⌘ ⇧ D | Go to the Desktop | Beginner | D for Desktop — jump straight to the desktop |

## Try it now

1. Press **⌘ ⇧ G**, type `~/Desktop`, and press ⏎ to teleport there
2. Press **Space** on any file to preview it without opening it
3. Press **⌘ ⇧ .** to reveal hidden files, then press it again to hide them
