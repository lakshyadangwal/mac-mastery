# 01 — Basics

Your coffee is cold. You typed a paragraph into the wrong window. You need that screenshot *now*. These are the shortcuts you use before lunch — the ones that make the computer feel like it actually listens.

## Shortcuts

| Keys | What it does | Level | Memory hook |
|------|--------------|-------|-------------|
| ⌘ C | Copy selected text or files | Beginner | C is for Copy — the photocopier living under your left thumb |
| ⌘ V | Paste from the clipboard | Beginner | V looks like a little delivery truck dropping off what you copied |
| ⌘ X | Cut — removes and copies at once | Beginner | X marks the spot where text leaves town |
| ⌘ Z | Undo your last action | Beginner | Z for Zip — zips your mistake back into its jacket |
| ⇧ ⌘ Z | Redo what you just undid | Power User | Shift + Z un-zips — brings the mistake back |
| ⌘ A | Select everything | Beginner | A for All — grabs the whole room |
| ⌘ ⌥ V | Paste and match style (no formatting) | Power User | Option keeps the paste plain, like plain oatmeal |
| ⌘ ⇧ 3 | Screenshot the entire screen | Beginner | 3 grabs everything — say cheese for the whole stage |
| ⌘ ⇧ 4 | Screenshot a selected area | Power User | 4 draws a box like a spy with a magnifying glass |
| ⌘ ⇧ 5 | Open the screenshot panel | Power User | 5 opens the clapperboard — capture, record, choose |
| ⌘ Space | Open Spotlight search | Beginner | Space at the bottom center launches the universe |
| ⌘ Tab | Switch between open apps | Beginner | Tab cycles apps like changing TV channels |
| ⌘ ` | Switch windows of the same app | Beginner | ` is the squiggle key that wiggles between windows |
| ⌘ H | Hide the current app | Power User | H for Hide — the app vanishes like a ninja |
| ⌘ M | Minimize the window | Beginner | M for Minimize — shrinks into the dock like a turtle |
| ⌘ Q | Quit the app entirely | Beginner | Q for Quit — closes the book for good |
| ⌘ , | Open the app's settings | Beginner | Comma is the settings key — the app's control panel |
| ⌥ ⌘ Esc | Force quit a frozen app | Power User | The three-finger salute when an app stops breathing |

## Try it now

1. Copy a line of text with **⌘ C**
2. Switch apps with **⌘ Tab**
3. Paste it somewhere new with **⌘ V**

Bonus: press **⌘ ⇧ 4**, draw a box, and admire your first screenshot.
