# mac-mastery Cheat Sheet

Print this and tape it to your monitor. One shortcut per day, five times a day.

## Modifier keys

| Symbol | Key |
|--------|-----|
| ⌘ | Command |
| ⌥ | Option |
| ⌃ | Control |
| ⇧ | Shift |
| ⎋ | Escape |
| ⌫ | Delete |
| ⏎ | Return |
| ⇥ | Tab |

## Beginner

| Keys | What it does |
|------|--------------|
| ⌘ C | Copy |
| ⌘ V | Paste |
| ⌘ Z | Undo |
| ⌘ A | Select All |
| ⌘ Space | Spotlight search |
| ⌘ Tab | Switch apps |
| ⌘ W | Close window |
| ⌘ H | Hide app |
| Space | Quick Look preview |
| ⌘ ⇧ 3 | Screenshot whole screen |
| ⌘ N | New Finder window |

## Power User

| Keys | What it does |
|------|--------------|
| ⇧ ⌘ Z | Redo |
| ⌘ ⌥ V | Paste and match style |
| ⌘ ⇧ 4 | Screenshot a selection |
| ⌃ ⬆ | Mission Control |
| ⌥ ← / → | Jump one word |
| ⌥ ⌫ | Delete a whole word |
| ⌃ ⌘ Space | Emoji picker |
| ⌘ ⇧ G | Go to Folder |
| ⌘ ⇧ . | Show hidden files |
| ⌥ ⌘ Esc | Force Quit |
| ⌥ ⌘ H | Hide all other apps |

## Wizard

| Keys | What it does |
|------|--------------|
| defaults write | Hidden macOS tweaks |
| pbcopy / pbpaste | Clipboard piping |
| caffeinate -i | Keep your Mac awake |
| ⌘ R at startup | Recovery Mode |
| ⌥ ⌘ 8 | Accessibility zoom |

## Memory hooks

- **Z** zips your mistake back into its jacket
- **4** draws a box like a spy with a magnifying glass
- **Option + delete** eats a whole word in one bite
- **Dot** reveals dotfiles like magic glasses
- **Space** peeks inside files like a keyhole
