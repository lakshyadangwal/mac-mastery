# 10 — Setup: New Mac

You just unboxed a shiny new Mac. It's beautiful, fast, and completely blank. Where do you even start?

## First-day checklist

- [ ] Update macOS — System Settings > General > Software Update
- [ ] Sign in with your Apple ID
- [ ] Set up Touch ID or Apple Watch unlock
- [ ] Turn on FileVault (disk encryption) — System Settings > Privacy & Security
- [ ] Enable iCloud Drive and Desktop & Documents syncing
- [ ] Set your computer name — System Settings > General > About
- [ ] Install your browser of choice
- [ ] Print or bookmark the [cheatsheet](../cheatsheet.md)
- [ ] Learn three shortcuts from 01-basics
- [ ] Set up Time Machine backups

## Recommended settings

| Setting | Where to find it | Why |
|---------|------------------|-----|
| Tap to click | System Settings > Trackpad | Click without pushing the trackpad down |
| Automatically hide and show the Dock | System Settings > Desktop & Dock | More screen space, Dock appears when you need it |
| "Automatically rearrange Spaces" off | System Settings > Desktop & Dock > Mission Control | Your desktops stay where you put them |
| Show path bar | Finder > View > Show Path Bar | Always know which folder you're in |
| Show all filename extensions | Finder > Settings > Advanced | See .pdf, .jpg, etc. at a glance |

## Try it now

1. Open System Settings and turn on **Tap to click**
2. Turn on **Automatically hide and show the Dock**
3. Learn one shortcut from each of your first three folders
