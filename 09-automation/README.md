# 09 — Automation

You do the same three clicks every morning. Your Mac can do them for you — while you get coffee.

## Automations

| Item | What it does | Level | Memory hook |
|------|--------------|-------|-------------|
| Shortcuts app | Build one-tap automations | Beginner | Lego blocks for your Mac — snap actions together |
| Text Replacements | Auto-expand short phrases | Beginner | Type "omw" → "On my way!" |
| Hot Corners | Trigger actions from screen corners | Power User | Swoop to a corner to start the screen saver |
| Automator | Record and repeat workflows | Power User | A robot that clicks for you |
| Folder Actions | Run tasks when files appear | Wizard | The folder watches itself and works |
| Services menu | Right-click to run automations | Power User | Right-click any file to transform it |
| Focus modes | Silence notifications by context | Beginner | Work, Sleep, Do Not Disturb — pick your vibe |
| Do Not Disturb schedule | Auto-silence at set times | Beginner | Set it and forget it — peace at bedtime |
| Quick Actions | Finder right-click shortcuts | Power User | Rotate images or make PDFs from the Finder |
| Print to PDF | Save anything as PDF | Beginner | Print → PDF: paper without the paper |
| Dictation | Speak instead of type | Beginner | Press fn twice and talk — your Mac types |

## Try it now

1. Open the Shortcuts app and make a shortcut that opens your three morning apps
2. Set a Hot Corner (System Settings > Desktop & Dock > Hot Corners) to start the screen saver
3. Add a text replacement: "addr" → your full address
