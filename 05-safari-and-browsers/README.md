# 05 — Safari and Browsers

You have forty tabs open, you just closed the one you needed, and a webpage is covered in ads. Time to take back your browser.

> Note: Reader Mode (⇧ ⌘ R) is a Safari feature. Other browsers have similar tools under different names or shortcuts.

## Shortcuts

| Keys | What it does | Level | Memory hook |
|------|--------------|-------|-------------|
| ⌘ T | Open a new tab | Beginner | T for Tab — opens a fresh page |
| ⌘ W | Close the current tab | Beginner | W for Window — closes this tab |
| ⇧ ⌘ T | Reopen the last closed tab | Beginner | Shift + T brings back the tab you just killed |
| ⌘ L | Jump to the address bar | Beginner | L for Location — your cursor lands in the URL bar |
| ⌘ R | Refresh the page | Beginner | R for Reload — get the latest version |
| ⌘ ⇧ R | Hard refresh | Power User | Shift forces a brand-new copy from the server |
| ⌘ ⇧ \ | Show all tabs at once | Power User | Backslash lays every tab out at once |
| ⇧ ⌘ R | Reader Mode (Safari) | Power User | Reader strips the noise like a highlighter |
| ⌥ ⌘ I | Open Web Inspector (dev tools) | Power User | Option + Command + I opens the developer tools |
| ⌘ D | Bookmark the page | Beginner | D for... save this page for later |
| ⇧ ⌘ B | Show the bookmarks bar | Beginner | B for Bookmarks — bring out the bar |
| ⌃ Tab / ⇧ ⌃ Tab | Next / previous tab | Power User | Control + Tab walks through your tabs |
| ⌘ 1–9 | Jump to tab number N | Beginner | Command + a number leaps to that tab |
| ⌘ + / ⌘ - | Zoom in / out | Beginner | Plus makes it bigger, minus makes it smaller |
| ⌘ 0 | Reset zoom to normal | Beginner | Zero puts everything back to normal size |
| ⌘ F | Find text on the page | Beginner | F for Find — search this page |

## Try it now

1. Press **⌘ L** and type a website
2. Press **⌘ ⇧ R** to hard-refresh the page
3. Press **⇧ ⌘ R** in Safari to enter Reader Mode (Safari only)
